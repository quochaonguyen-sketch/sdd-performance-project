# On-Hold Analytics

Inherits MASTER.md and shared light/dark semantic tokens.

- Keep the default view focused on one time/area toolbar, one OH total, and ward/rider tables. Do not add metric cards, area cards, collection logs, or repeated explanatory panels.
- Extra geography and reason filters live in a compact disclosure. Show active filters beside the period total.
- Tables show ten rows per page, with one shared search field. Use plain names, secondary identifiers, OH count and share; avoid rank medals, avatars, gradients and decorative progress bars.
- Place daily reasons, hours, order drill-down and the daily area pivot inside the collapsed daily details section. Compute these only when expanded.
- Preserve missing-data dashes and concise incomplete-period warnings. Multi-day totals count OH occurrences, not globally unique orders.
- Use two table columns when space permits and stack on smaller containers. Wide tables scroll within their own region, controls have visible focus, and mobile inputs use 16px text and 44px targets.

- Use one graphite summary band with inverse text and a compact shared search. Keep the time control bounded in width; avoid stretching it across the toolbar.
- Ranking panels use restrained section icons, 64px rows, sticky column headers and a 426px inner viewport. Counts and identifiers remain typographically distinct; no decorative charts or avatars.

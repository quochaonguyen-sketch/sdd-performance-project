# On-Hold Analytics

Inherits MASTER.md and shared light/dark semantic tokens.

- Keep the overview outside the legacy report workspace so descendant rules for labels, headings and tables cannot override the overview.
- Use a page container for responsive filters. Stack geography/rider ranking panels with wide tables scrolling inside their own bordered viewport.
- Keep labels and filter values readable; use full-width date and area selectors on small screens, with 44px targets and visible focus.
- Preserve missing-data dashes, partial-day warnings, daily/weekly comparisons and existing calculations.
- Use readable semantic foreground/background pairs for hour cells and dark-mode badges.

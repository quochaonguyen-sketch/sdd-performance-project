# Pickup Backlog

Follows MASTER.md and UI/UX Pro Max Data-Dense Dashboard guidance.

- Unboxed header: title, update timestamp, refresh and permission-controlled SPX sync.
- Geography overview: a single divided strip for unique orders, order COT counts and priority wards.
- One command panel: view tabs, source/queue status, six compact area choices and filters. Area choices show order counts only in the geography view; rider COT filters mean rider responsibility.
- Main workspace: KV → district → ward, eight fixed ward rows with independent scrolling and existing scoped order dialogs. Keep names at 12px and avoid excessive card padding.
- Rider groups use the same area header and divided metric strip; preserve unique rider summaries and multi-area scope.
- Charts are collapsed secondary analysis beneath the operational list.
- Semantic surfaces and colors support both themes. At 600px, metrics use two columns, areas use three, inputs use 16px and controls retain 44px touch targets.
- No changes to snapshot publication, refresh/queue lifecycle, order scope, permissions or database functions.

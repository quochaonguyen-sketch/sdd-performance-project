# Backlog History

Inherits SDD Operations MASTER.md, semantic tokens and IBM Plex Sans.

- Workflow: choose date/area/COT → select Pickup or Delivery → inspect daily trend and 24 hourly snapshots → compare two snapshots by area, district or ward.
- Use two source cards, four compact KPIs and one full-width trend panel. Keep hourly selection beside the trend in the same panel.
- Put A/B comparison before optional hourly-change and heatmap analysis. Keep special 16:00/16:30 checkpoint details separate.
- Default comparison sorting prioritizes absolute change; offer rising, falling and geographic order without changing totals.
- Missing snapshots display a dash and gaps in charts. A captured zero remains zero. Mark provisional/final data with text and line styles, alongside semantic colors.
- Preserve capture schedules, snapshot selection rules, COT calculations and source timestamps.
- On narrow screens stack source cards, wrap filters, keep controls at least 44px and scroll charts/tables within their panels.
- Use keyboard-operable controls, visible focus and a labeled native chart dialog with Escape support.
- Trend defaults to the observed hourly range with a full-day toggle. Show per-source values/status/hourly changes in a fixed readout, a crosshair for the inspected hour and clickable daily peak summaries. Keep linear segments truthful; never interpolate missing snapshots.
